# Taplink Pay

A responsive, static frontend concept for a Taplinkuzb payment-choice page.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site. The URL will be `https://taplinkuzb.github.io/taplink-pay/`.

## Payment integration status

The current page is a visual prototype. Payme, Click, Paynet and Uzum are intentionally shown as unavailable until the merchant account and payment flow are configured.

Do not put merchant secrets, API passwords, signing keys or private tokens in browser-side JavaScript. Dynamic payment creation and verification must be handled by a secure backend or an approved payment provider integration. Configure each provider using its official merchant onboarding and developer documentation.
